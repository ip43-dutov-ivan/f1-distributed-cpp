# Лабораторна робота 7 (варіант 4)

Сервер і два клієнти на Win32 з передачею даних через іменовані канали (**Named Pipes**, `\\.\pipe\lab7`).

Варіант розраховано за методичкою (`ЛБ_07.pdf`): `9 - (варіант ЛБ_06 = |2 - 7| = 5) = 4` (завдання з таблиці №1 `ЛБ_04.pdf`).

## Вимоги

- Windows 10/11 (`ARM64`, `x64` або `Win32`);
- Visual Studio з робочим навантаженням «Розробка настільних застосунків C++», стандарт C++20;
- `Comctl32` підключається через `#pragma comment(lib)`.

## Збирання

1. Відкрити `CppLab7/CppLab7.slnx`.
2. Обрати конфігурацію (наприклад, `Debug` або `Release`, платформа `ARM64` чи `x64`).
3. Зібрати рішення. Спочатку збирається статична бібліотека `Common`, потім три виконувані файли (`Server`, `Client1`, `Client2`).

## Запуск

1. Запустити `Server`, у меню `Pipe` обрати `Create` (створює `\\.\pipe\lab7` із перекритим вводом/виводом у фоновому потоці та надсилає підтвердження клієнтам).
2. Запустити `Client1` та `Client2` і натиснути `Send Metrics` (або `Ctrl+Enter`).
3. Ім'я віддаленого хоста можна передати в командному рядку клієнта; за замовчуванням використовується `.` (локальна машина).

У Visual Studio можна налаштувати одночасний запуск: `Solution → Configure Startup Projects → Multiple startup projects` і виставити `Start` для `Server`, `Client1`, `Client2`.

## Що робить кожен застосунок

| Застосунок | Що робить / надсилає серверу | Команда |
| --- | --- | --- |
| `Server` | Створює `\\.\pipe\lab7` (`PIPE_ACCESS_DUPLEX \| FILE_FLAG_OVERLAPPED`), приймає повідомлення, відповідає клієнту кількістю прийнятих байтів | `Pipe → Create` / `Pipe → Close` |
| `Client 1` | Варіант 4: прапорці дигітайзера (`SM_DIGITIZER`), стан мережі (`SM_NETWORK`, у методичці `SM_NETCAPTURE`), ширина екрана (`HORZRES`) | `Client → Send Metrics`, кнопка або `Ctrl+Enter` |
| `Client 2` | Варіант 4: висота малого заголовка (`SM_CYSMCAPTION`), товщина фіксованої рамки (`SM_CXFIXEDFRAME`), кількість кольорів (`NUMCOLORS`) | `Client → Send Metrics`, кнопка або `Ctrl+Enter` |
