# Лабораторна робота 5 (варіант 7)

Сервер і три клієнти на Win32 з передачею даних через поштові скриньки (**Mailslots**, `\\.\mailslot\lab5`).

Варіант розраховано за методичкою (`ЛБ_05.pdf`): `9 - (варіант ЛБ_04 = 2) = 7` (завдання з таблиці №1 `ЛБ_04.pdf`), плюс завдання «з зірочкою» — Клієнт 3 із математичними обчисленнями.

## Вимоги

- Windows 10/11 (`ARM64`, `x64` або `Win32`);
- Visual Studio з робочим навантаженням «Розробка настільних застосунків C++», стандарт C++20;
- `Comctl32` підключається через `#pragma comment(lib)`.

## Збирання

1. Відкрити `CppLab5/CppLab5.slnx`.
2. Обрати конфігурацію (наприклад, `Debug` або `Release`, платформа `ARM64` чи `x64`).
3. Зібрати рішення. Спочатку збирається статична бібліотека `Common`, потім чотири виконувані файли (`Server`, `Client1`, `Client2`, `Client3`).

## Запуск

1. Запустити `Server`, у меню `Mailslot` обрати `Create` (створює `\\.\mailslot\lab5` і запускає опитування через `GetMailslotInfo` + `ReadFile` кожні 500 мс).
2. Запустити `Client1`, `Client2`, `Client3` і натиснути кнопку відправки (або `Ctrl+Enter`).
3. Ім'я хоста або `*` (широкомовна розсилка в домені) можна передати в командному рядку клієнта; за замовчуванням використовується `.` (локальна машина).

У Visual Studio можна налаштувати одночасний запуск: `Solution → Configure Startup Projects → Multiple startup projects` і виставити `Start` для `Server`, `Client1`, `Client2`, `Client3`.

## Що робить кожен застосунок

| Застосунок | Що робить / надсилає серверу | Команда відправки |
| --- | --- | --- |
| `Server` | Створює `\\.\mailslot\lab5`, опитує чергу за таймером, виводить прийняті повідомлення та закриває скриньку | `Mailslot → Create` / `Mailslot → Close` |
| `Client 1` | Варіант 7: режим завантаження (`SM_CLEANBOOT`), мін. ширина вікна (`SM_CXMIN`), ширина екрана (`HORZRES`) | `Client → Send Metrics`, кнопка або `Ctrl+Enter` |
| `Client 2` | Варіант 7: висота кнопок меню (`SM_CYMENUSIZE`, у методичці `SM_CYBUTTON`), мін. ширина відстеження (`SM_CXMINTRACK`), висота екрана (`VERTRES`) | `Client → Send Metrics`, кнопка або `Ctrl+Enter` |
| `Client 3` | Завдання «з зірочкою»: обчислює площу, периметр і діагональ прямокутника за введеними `a` і `b` та надсилає результат | `Client → Calculate & Send`, кнопка або `Ctrl+Enter` |
