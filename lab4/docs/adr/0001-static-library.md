# 0001. Спільний код у статичній бібліотеці

- Статус: прийнято

## Контекст

Сервер і три клієнти використовують одні й ті самі вікно, мережевий шар, протокол та елементи інтерфейсу. Спочатку кожен проєкт компілював файли з `Common` напряму, тому Visual Studio показувала їх у кожному проєкті, і виглядало, що код продубльовано.

## Рішення

`Common` це окремий проєкт зі статичною бібліотекою (`Common.vcxproj`). Решта чотири проєкти підключають її через `ProjectReference`.

## Наслідки

- Кожен файл існує в одному екземплярі й показується в Visual Studio один раз.
- Правка в `Common` потрапляє у всі застосунки при наступному збиранні.
- Збирання вимагає порядку: бібліотека, потім виконувані файли. Visual Studio робить це сама за `ProjectReference`.
- Директиви `#pragma comment(lib, ...)` у бібліотеці передаються до компонувальника застосунків, тому налаштовувати `Ws2_32` у кожному проєкті не потрібно.
- Динамічна бібліотека (DLL) не потрібна: усі застосунки збираються разом, а окремо поширювати бібліотеку нікому.
